1. 目标与可行性结论

1.1 诉求

将动力性分析中环境舒适度、设施完善度、政策支持度三项准则，由当前「多子图层取最大值（MAX）」改为「多子图层得分相加（SUM）」，使准则层原始分值自然分布在 0～5，并可映射为 1～5 档梯度，增强图面层次与空间差异表达。

结论：可行。三项准则的子图层分值本身即为小整数（1～2 分/层），SUM 后天然形成 0～5 量级，与交通便捷度（理论满分 5）在数量级上对齐；仅需将准则内合并方式由 CellStatistics MAXIMUM 改为 SUM，并同步更新理论满分与标准化分母。

1.2 范围说明

准则是否纳入本次改造说明
交通便捷度否含路网五档 + 地铁多环 MAX，逻辑独立；维持现状
环境舒适度是生态廊道 + 开敞空间 + 绿地 → SUM
设施完善度是市级公服 + 便民 + 商业 → SUM
政策支持度是发展圈带 + 战略片区 + 近期重点 → SUM

2. 现状：MAX 合并的问题

2.1 当前实现路径

子图层缓冲/栅格化
各得 1～2 分 → CellStatistics
MAXIMUM → 准则原始分
理论满分 = 2 → ÷2 ×100
标准化 0–100 → 四准则加权
mot_score

对应代码：MotivationAnalysisEngine.BuildEnvironment/BuildFacility/BuildPolicy 末尾调用 BufferScoreRasterBuilder.MaxCombine；MotivationScoreScale 中 EnvironmentMax / FacilityMax / PolicyMax 均为 2.0。

2.2 MAX 带来的局限

现象机制
准则内只有 2～3 个有效档位 三层叠加取 MAX 后，像元值只能是 {0, 1, 2}，无法区分「仅一种设施」与「三种设施齐备」
图面斑块单调 缓冲圈重叠区与非重叠区得分相同（都被 MAX 封顶为 2），空间梯度弱
与交通五档不对等 交通理论满分 5、环境/设施/政策满分 2，标准化后三项「容易顶满」，区分度不足
政策区叠加无增量 同时落在「发展圈带(1) + 战略片区(1) + 近期重点(2)」的像元，MAX 后仍为 2，政策强度被低估
示例：某像元同时靠近生态廊道(2)、开敞空间(2)、公园绿地(1)。
MAX → 2；SUM → 5。后者更能表达「环境要素富集」。

3. 推荐方案：SUM 叠加 + 1–5 梯度

3.1 核心公式

环境_raw = SUM( 生态廊道缓冲分, 开敞空间缓冲分, 绿地缓冲分 )
设施_raw = SUM( 市级公服缓冲分, 便民设施缓冲分, 商业设施缓冲分 )
政策_raw = SUM( 发展圈带分, 战略片区分, 近期重点区分 )

准则标准化（与现逻辑一致，仅改分母）：
　准则_100 = (准则_raw / 理论满分) × 100

动力性总分（不变）：
　mot_score = Σ (准则_100 × 权重) / Σ权重

3.2 理论满分调整

准则现理论满分改后理论满分依据
环境舒适度25 2 + 2 + 1 = 5（沿用现有缓冲赋分，无需改分）
设施完善度25 见 4.2：建议商业设施 1→2，使 2+1+2=5；或保持 4 为满分
政策支持度24 或 5 现 1+1+2=4；建议近期重点 2→3 对齐五档，或接受 1–4 自然梯度
交通便捷度55不变

3.3 准则层 1–5 档（展示用，可选输出）

准则原始分 SUM 后可直接按整数映射为五级，便于专题图与汇报（与 pot_level 语义平行，但作用于单项准则）：

准则_level =
　0 → 无（或 NoData，不参与展示）
　1 → 1 档（偏弱）
　2 → 2 档（较低）
　3 → 3 档（中等）
　4 → 4 档（较高）
　≥5 → 5 档（富集/极强，封顶）
0 无
1 档
2 档
3 档
4 档
5 档

说明：0 档可不设色；1–5 为准则内相对强度，与最终 pot_level 的 0–100 等距断点无关。建议成果中同时保留连续值（标准化 0–100）与五级专题图。

推荐采用方案 B（对齐五档）：
① 三项准则内合并统一改为 SUM；
② 理论满分：环境=5、设施=5（商业调为 2 分）、政策=5（近期重点调为 3 分）；
③ 输出中间栅格：env_raw / fac_raw / pol_raw（0–5）及可选 env_lvl / fac_lvl / pol_lvl（1–5）；
④ 标准化分母同步改为 5，再进入现有四准则加权流程。

6. 对动力性总分与下游的影响

6.1 标准化分母变化

改前：环境像元 raw=2 → 环境_100 = 2/2×100 = 100（易顶满）
改后：环境像元 raw=2 → 环境_100 = 2/5×100 = 40（中等偏上）
改后：环境像元 raw=5 → 环境_100 = 5/5×100 = 100（需多要素叠加才顶满）

三项准则「顶满」难度提高，mot_score 整体可能略降，空间对比度增强。若与历史项目对比，需在报告中注明算法版本。

6.2 对 pot_score 的间接影响

动力性权重默认 70%，环境/设施/政策各占动力性 20%～25% 量级。SUM 后：

  • 要素富集区（老城中心、政策叠加区）动力性抬升更明显
  • 单一要素边缘区不再轻易拿到准则满分，与交通/可行度形成更合理梯度
  • 最终 pot_level 五色分布可能改善（中间档减少「虚假顶满」）

6.3 历史结果可比性

改算法后 mot_score 数值不可与旧版直接对比。建议：保留旧版 GDB 备份；新版导出时文件名或元数据标注 mot_v2_sum；验收阶段做同范围新旧直方图对照。

场景 子层得分 MAX（现） SUM（改） 标准化/5×100
仅公园绿地缓冲内 0+0+1 1 1 20
湖泊 + 绿地 0+2+1 2 3 60
廊道 + 湖泊 + 绿地 2+2+1 2 5 100
仅市级公服 2+0+0 2 2 40
公服 + 便民 + 商业（方案 B） 2+1+2 2 5 100

SUM 的核心价值：区分「有一项」与「多项齐备」，使准则层像元值从 {0,1,2} 扩展为 {0,1,2,3,4,5}，图面自然出现五级色带。

8. 风险与对策

风险说明对策
缓冲圈大面积重叠 同一准则内多个点/面缓冲相交，SUM 可能普遍偏高 保持现有缓冲半径；验收时看 raw 直方图；必要时对 SUM 结果 Min(5, raw) 封顶
政策面嵌套重复计分 重点区落在圈带内，三层分全加 默认保留 SUM（政策意图为叠加）；
备选：按优先级只取最高层（等效 MAX，不推荐）；
或：内层计全分、外层计差分（需改面处理逻辑）
设施/政策满分不到 5 若不调分，满分分别为 4 标准化分母用实际满分 4；或按方案 B 微调单层分至合计 5
与旧成果不可比 mot_score 数值整体下移或分布改变 版本标注 + 同范围 A/B 报告；对外用相对分级（pot_level）时说明断点口径
缺子图层时满分缩水 如某城无战略片区，政策 SUM 满分仅 4 或更低 标准化分母按本次实际参与子层之和动态计算（进阶）；或日志明确提示「理论满分已调整为 X」

10. 验收建议

  1. 准则 raw 直方图：环境/设施/政策 SUM 后应出现 0～5（或 0～4）多个峰值，而非仅集中在 2
  2. 目视检查：多要素叠加区（如公园+河道+绿地、公服+商业集聚、政策三重区）颜色应明显深于单一要素区
  3. 顶满面积：raw=5 的像元占比应合理（不宜 >30% 全城，否则检查缓冲半径或嵌套计分）
  4. mot_score 对比：新旧版同范围均值/分位数变化在可解释范围内；附对照表
  5. 五级专题（若输出）：env_lvl / fac_lvl / pol_lvl 各级面积均 > 0
  6. 回归：交通便捷度、叠置、导出流程无变化；缺图层时仍优雅跳过
